Для запуска установите JDK 21 и Maven, затем из корня репозитория выполните:

```powershell
mvn javafx:run
```

## Работа с API эмулятора

В приложении есть раздел «Получение данных из внешнего API». Выберите тип
данных и нажмите «Получить данные». Доступны методы `fullName`, `snils`,
`inn`, `email` и `identityCard`.

### Что реализовано

- Выбор типа данных в выпадающем списке.
- Асинхронный GET-запрос к выбранному endpoint API.
- Отображение значения из JSON-поля `value`.
- Проверка ФИО на запрещённые символы и наличие трёх частей.
- Сообщение при недоступности сервера без аварийного завершения приложения.
- Отдельное сообщение для ошибки сервера HTTP 500.

Адрес эмулятора для сети колледжа уже задан в программе:

```text
http://192.168.1.200:4444/TransferSimulator/
```

Дома этот адрес недоступен: приложение должно показать сообщение о проблеме
подключения и продолжить работу. В колледже перед запуском приложения
проверьте выбранный endpoint через Bruno. Если сервер вернул HTTP 500,
сообщите об этом главному эксперту.

Для `fullName` приложение проверяет отсутствие запрещённых символов и наличие
трёх частей ФИО.

## Логика

- Калькулятор двух чисел: сложение и вычитание.
- Добавление имён в список.
- Проверка введённых данных на лишние символы.
- Очистка лишних символов.
- Защита от повторного добавления одинаковых имён.
- Удаление имён из списка.
- Выбор элемента списка мышкой.
- Навигация по списку с помощью клавиш ↑ и ↓.
- Отмена последнего изменения через кнопку или `Ctrl + Z`.
*работает только на английской раскладке
- Уведомления о действиях пользователя.
- Диалог подтверждения очистки лишних символов.
