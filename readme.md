## Алгоритмы — desktop-версия

Исходное веб-приложение сохранено в корне (`index.html`, `script.js`, `style.css`).
Его самостоятельная desktop-версия реализована на Java 21 и JavaFX в `src/`.

Для запуска установите JDK 21 и Maven, затем из корня репозитория выполните:

```powershell
mvn javafx:run
```

## Сохранённая логика

- Калькулятор двух чисел: сложение и вычитание.
- Добавление имён в список.
- Проверка введённых данных на лишние символы.
- Очистка лишних символов.
- Защита от повторного добавления одинаковых имён.
- Удаление имён из списка.
- Выбор элемента списка мышкой.
- Навигация по списку с помощью клавиш ↑ и ↓.
- Отмена последнего изменения через кнопку или `Ctrl + Z`.
*работает только на английской раскладке
- Уведомления о действиях пользователя.
- Диалог подтверждения очистки лишних символов.
