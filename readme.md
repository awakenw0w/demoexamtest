## Требования

Для запуска установите JDK 21 и Maven.

### JDK 21

Откройте PowerShell и выполните:

```powershell
winget install --id EclipseAdoptium.Temurin.21.JDK -e
```

После установки проверьте:

```powershell
java -version
```

## Maven

Установите Maven через PowerShell:

winget install -e --id eye942.Maven

После установки откройте новое окно PowerShell и проверьте:

mvn -version

## Запуск локального API

В проекте есть собственный локальный эмулятор API `TransferSimulator`.

Перед запуском приложения необходимо запустить локальный сервер.

Из корня проекта выполните:

```powershell
cd ".\Transfer Simulator"
```

Скомпилируйте сервер:

```powershell
javac -encoding UTF-8 TransferSimulator.java
```

Запустите его:

```powershell
java -cp . TransferSimulator
```

После запуска сервер будет доступен по адресу:

```text
http://localhost:4444/TransferSimulator
```

Доступные методы:

```text
GET /fullName
GET /snils
GET /inn
GET /email
GET /identityCard
```

Например:

```text
http://localhost:4444/TransferSimulator/fullName
```

Сервер возвращает тестовые данные клиентов. Значение выбирается случайным образом, поэтому при повторных запросах могут приходить разные данные.

Окно PowerShell с запущенным сервером необходимо оставить открытым.

## Запуск приложения

После запуска локального API откройте **новое окно PowerShell**.

Перейдите в корень проекта

Запустите приложение:

```powershell
mvn javafx:run
```

Приложение подключается к локальному API:

```text
http://localhost:4444/TransferSimulator
```

---

### Что еще реализовано

* Выбор типа данных в выпадающем списке.
* GET-запрос к выбранному endpoint API.
* Получение значения из JSON-поля `value`.
* Отображение полученного значения.
* Проверка полученных данных.
* Отдельное сообщение для ошибки сервера HTTP 500.

Для `fullName` приложение проверяет отсутствие запрещённых символов и наличие трёх частей ФИО.

---

## Алгоритмы

* Калькулятор двух чисел: сложение и вычитание.
* Добавление имён в список.
* Проверка введённых данных на лишние символы.
* Очистка лишних символов.
* Защита от повторного добавления одинаковых имён.
* Удаление имён из списка.
* Выбор элемента списка мышкой.
* Навигация по списку с помощью клавиш ↑ и ↓.
* Отмена последнего изменения через кнопку или `Ctrl + Z`.

*Работает только на английской раскладке.*

* Уведомления о действиях пользователя.
* Диалог подтверждения очистки лишних символов.
